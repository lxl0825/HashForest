# HashForest

HashForest is a distributed, self-healing data grid utilizing a scalable, distributed-hash-table architecture to optimize query performance.

HashForest is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/HashForest.git`
2. `cd HashForest`
3. Install in editable mode: `pip install -e .`

## Configuration

HashForest is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
